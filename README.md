mlops-mini-project
==============================

A small mlops projects end to end

Steps for this project: 
1. Using cookie cutter data science template 
2. setting up the entire data preprocessing part including feature engineering and model building
3. Finally connecting to dagshub
4. DVC Pipeline - Data versioning and code versioning
5. And lastly, connecting to mlflow
6. Using model registry from mlflow too
7. Experiment tracking and final clean up.
